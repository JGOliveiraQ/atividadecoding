# Pokédex Explorer

Aplicativo mobile em React Native com Expo que apresenta uma Pokédex consumindo dados da PokeAPI.

## Funcionalidades

- Listagem paginada de Pokémon
- Busca por nome ou número
- Atualização por pull-to-refresh
- Imagens oficiais e tipos de cada Pokémon
- Navegação entre catálogo, detalhes e favoritos
- Favoritos persistidos localmente com AsyncStorage
- Interface construída com React Native Paper
- Estados de carregamento, erro e lista vazia

## Tecnologias

- React Native
- Expo
- TypeScript
- PokeAPI

## Como executar

```bash
npm install
npm start
```

Use o Expo Go no celular ou execute no navegador com:

```bash
npm run web
```
