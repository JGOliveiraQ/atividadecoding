# Pokédex Explorer

Aplicativo mobile em React Native com Expo que apresenta uma lista de Pokémon consumidos diretamente da PokeAPI.

## Funcionalidades

- Listagem paginada de Pokémon
- Busca por nome ou número
- Atualização por pull-to-refresh
- Imagens oficiais e tipos de cada Pokémon
- Estados de carregamento, erro e lista vazia

## Tecnologias

- React Native
- Expo
- TypeScript
- PokeAPI

## Como executar

```bash
npm install
npm start
```

Use o Expo Go no celular ou execute no navegador com:

```bash
npm run web
```
